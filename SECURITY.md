# Security policy

## Supported versions

Security fixes target the latest published version of Codex Usage Tray.

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/MatthiasHeinsius/codex-usage-tray/security/advisories/new) to report a security issue. Do not open a public issue.

Include the affected version, steps to reproduce the issue, its expected impact, and any suggested fix. The maintainer will acknowledge the report, investigate it, and coordinate disclosure with you.
